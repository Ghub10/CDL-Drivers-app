# Feature Priority
## CDL Drivers — MVP vs Phased Enhancements

---

## MVP

Core features required for launch. Without these, the product cannot fulfill its purpose.

| Feature | Reasoning |
|---------|-----------|
| Driver and recruiter sign up with email verification | Required for two-sided marketplace and trust |
| Driver profile (name, phone, email, CDL classes, endorsements, location, availability, resume) | Core value — recruiters need this data to find drivers |
| Recruiter search (city, zip/radius, map) with CDL/endorsement filters | Main recruiter workflow to discover drivers |
| Driver list and detail views with contact info | Enables connection and outreach |
| In-app messaging | Direct communication per requirements |
| Email notifications on new message | Driver awareness without requiring app open |
| No-connection message when offline | Explicit requirement; simple UX |

---

## Phase 2 Enhancements

Improve engagement and retention after MVP launch.

| Feature | Reasoning |
|---------|-----------|
| Browser push notifications | Faster response than email alone |
| Saved searches / favorites for recruiters | Reduces repeat work, increases return visits |
| Recruiter company profile enhancements | Trust and credibility |
| Driver profile completeness indicator | Encourages complete profiles |
| Optional automated phone call alerts | User requested; requires telephony (Twilio, etc.) |

---

## Future Ideas

Not committed; evaluate based on user feedback and metrics.

| Feature | Reasoning |
|---------|-----------|
| CDL/document verification | Reduces fraud; requires manual or third-party integration |
| Analytics dashboard for recruiters | Premium/enterprise value |
| Driver application tracking | Workflow beyond initial contact |
| Map clustering and advanced filters | Better UX at scale |
| Premium subscription model | Revenue |
